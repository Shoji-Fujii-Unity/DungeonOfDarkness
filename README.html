DUNGEON OF DARKNESS

HTML5JavaScriptNo dependenciesMobile / PCJA / EN

▶ はじめに

index.html 1ファイルだけで動作する、ウィザードリィ風のターン制ダンジョンRPGです。インストールもビルドも不要で、ブラウザを開くだけですぐ遊べます。スマホ(縦長画面)主体に設計していますが、PCでもキーボード操作でプレイできます。

▶ 遊び方

  1. index.html をブラウザで開く
  2. 「冒険を始める」→ パーティー4人を編成 → 「迷宮へ降りる」
  3. 地下5階の玉座に封じられた古代のリッチ王を倒せば勝利!

▶ 技術メモ

  • 依存ゼロの単一HTML(HTML + CSS + Vanilla JS)
  • 迷宮はランダム化DFS迷路に部屋を追加して生成し、階段・施設は歩行可能な連結領域に配置
  • 3D描画は canvas 上の DDA レイキャスト。モンスターは低解像度キャンバスからドット絵として描画
  • セーブデータ: localStorage キー grimoire_souls_save_v1
  • 敵・装備・種族/職業ステータスはスクリプト冒頭のデータオブジェクトで管理されており、テーブル追加だけで拡張可能

▶ Overview

A Wizardry-like turn-based dungeon RPG that runs from a single index.html. No install, no build — just open it in a browser. Designed primarily for portrait-mode smartphones, with keyboard support on desktop.

▶ How to Play

  1. Open index.html in any modern browser
  2. "NEW GAME" → build a party of 4 → "ENTER DUNGEON"
  3. Descend 5 floors and defeat the Lich King sealed on the deepest throne!

Character Creation

ItemDetails
NameType your own or roll 🎲
RaceHuman / Elf / Dwarf (different base stats)
ClassFighter / Mage / Priest / Thief (unique spells & gear restrictions)
BonusRoll 3d6 points and allocate freely to HP(+5)/MP(+3)/ATK/DEF/SPD. Re-rolling resets allocation

Exploration & Combat

  • Move: ◀ ▶ turn, ▲ step, ↩ u-turn. "LOOK" inspects stairs, merchant, healer or chests ahead
  • MAP button: toggle minimap (explored area only)
  • Traps: Thieves excel at spotting them
  • Combat: speed-ordered command battle — Attack / Spell / Item / Flee, tap to pick a target. Failed escapes waste your turn; the boss can't be fled from

Equipment System

5 slots: Weapon / Two-handed / Helm / Armor / Shield
Exclusivity: 2H weapons and shields can't be worn together — equipping one automatically unequips the other back to party storage
Class limits: e.g. Greatswords & Plate Mail = Fighter only, Robes = Mage/Priest only
Loot: chests (~40%) and monster drops (~25%+). Deeper floors yield higher-tier gear (Tier 1–3); the boss always drops Tier 3
Change gear: tap a party member chip → STATUS screen. Stats display with bonuses included

▶ Tech Notes

  • Zero-dependency single HTML file (HTML + CSS + vanilla JS)
  • Randomized DFS maze with connected chambers; stairs and services are placed on reachable floor tiles
  • DDA raycasting with floor-specific wall/floor palettes; monsters are rendered as low-resolution pixel art
  • Save data: localStorage key grimoire_souls_save_v1
  • Enemies, equipment and class/race stats are plain data objects at the top of the script — extend by editing tables only
